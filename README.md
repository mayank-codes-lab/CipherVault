# 🔐 CipherVault

> **A Professional Secure File Encryption & Decryption System built with Java.**

CipherVault is a secure file encryption application designed to protect sensitive files using modern cryptographic techniques. The project follows a clean layered architecture and focuses on secure file handling, encryption, validation, and user-friendly console interaction.

> **🚧 Project Status:** Currently Under Active Development

---

## 📌 Project Overview

CipherVault is being developed as a real-world security-focused Java application that allows users to securely encrypt and decrypt files using password-based encryption.

The objective of this project is to simulate how professional encryption software works while applying software engineering principles, object-oriented programming, clean architecture, exception handling, and Java file management.

---

## 🎯 Project Goals

- Protect confidential files using encryption
- Prevent unauthorized access to sensitive data
- Practice real-world Java backend development
- Demonstrate secure programming concepts

# ✨ Current Features

### ✅ Console Based User Interface

- Interactive menu-driven application
- Clean and user-friendly navigation

### ✅ File Validation

- Validate empty file path
- Check file existence
- Verify file readability
- Detect supported file types
- File permission validation

### ✅ File Processing

- Read file contents
- Store file data in memory
- Display complete file information
- Display file metadata
- Handle invalid file scenarios

### ✅ Metadata Extraction

Displays

- File Name
- Absolute Path
- File Size
- Read Permission
- Write Permission
- Last Modified Date
